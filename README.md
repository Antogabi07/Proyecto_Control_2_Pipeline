# Proyecto_Control_2_Pipeline
Pipeline en Python para la selección del Conjunto Mínimo de Datos (MDS) y cálculo del Índice y Brecha de Salud del Suelo (SHI/SHG) en la cuenca del Río Maipo
# Pipeline para la Evaluación de la Salud del Suelo (SHI / SHG)

## Propósito del Proyecto
Desarrollar un pipeline en Python para la selección automatizada de un Conjunto Mínimo de Datos (MDS) y la cuantificación del Índice de Salud del Suelo (SHI) y la Brecha de Salud del Suelo (SHG), comparando ecosistemas de referencia nativos con suelos bajo manejo vitícola en la cuenca del Río Maipo.

## Pregunta de Investigación
¿De qué manera el cambio de uso de suelo afecta la capacidad funcional edáfica y determina la Brecha de Salud del Suelo (SHG) al comparar un ecosistema de referencia no intervenido con un sistema agrícola vitícola?

## Variables de Interés
- Propiedades Físicas: Textura (Bouyoucos), Densidad Aparente (Db), Porosidad Total (TP) y Capacidad de Agua Aprovechable (AWC).
- Propiedades Químicas:pH, Conductividad Eléctrica (CE), Carbono Orgánico del Suelo (COS) y Carbonato de Calcio equivalente (CaCO3).
- Propiedades Biológicas: Carbono de Biomasa Microbiana (CBM), Respiración Microbiana Basal (RMS) y Macrofauna (lombrices).
